# Init Project Spec

## Overview

Clean the Create Next App boilerplate so the index (`/`) only shows an `h1` with "Panda Metrics", align the project structure with `context/coding-standars.md`, and connect the local repository to `git@github.com:Ellyonsoft/panda-metrics.git` with a first push to `main`. This leaves a clean base for the Foundation phase of the project overview.

## Requirements

### Structure (coding standards)

- Move `app/` to `src/app/` (`page.tsx`, `layout.tsx`, `globals.css`, `favicon.ico`). No `app/` folder may remain at the root, because Next.js ignores `src/app` when `app/` exists
- Keep `public/`, `package.json`, `next.config.ts`, `tsconfig.json`, `eslint.config.mjs` and `.env*` files at the root
- `tsconfig.json`: change the `@/*` path to `["./src/*"]`
- Do not create `tailwind.config.*`. Tailwind v4 detects `src/` on its own; all theme config stays in `src/app/globals.css` with `@theme`
- Do not create the empty `src/components`, `src/lib`, `src/actions` or `src/types` folders yet; they are added by the features that need them

### Page and layout

- `src/app/page.tsx`: Server Component (no `'use client'`) that only renders `<h1>Panda Metrics</h1>`, centered with Tailwind classes. Remove the `next/image` import, logo, links and Deploy/Docs buttons. No inline styles
- `src/app/layout.tsx`: metadata title "Panda Metrics" and a real description (feedback collection, survey management and metrics). Keep the `LayoutProps<"/">` global helper (no import needed in Next.js 16). Keep `lang="en"` until next-intl is added. Keep the Geist fonts

### Styles

- `src/app/globals.css`: keep `@import "tailwindcss"` and the `@theme inline` block
- Light mode first: the light colors (`--background: #ffffff`, `--foreground: #171717`) stay as the default in `:root`. Replace the `prefers-color-scheme` media query with a `.dark` class holding the dark colors (`#0a0a0a`, `#ededed`), so the system theme no longer switches it; the dark theme toggle comes later with shadcn/ui and `next-themes`
- Remove the `font-family: Arial, Helvetica, sans-serif` override on `body` so `--font-sans` (Geist) applies

### Cleanup

- `public/`: delete the unused boilerplate SVGs (`file.svg`, `globe.svg`, `next.svg`, `vercel.svg`, `window.svg`)
- `README.md`: replace the Create Next App text with a short project description and how to run it (`yarn install`, `yarn dev`)
- Keep `next.config.ts` as is (`cacheComponents`, `partialPrefetching`, Tailwind Turbopack loader)
- Commit the `AGENTS.md` block generated by `next dev` as is
- No unused imports, variables or commented-out code
- Do not install shadcn/ui, next-intl, TanStack Query or Prisma in this feature

## Verification

- `yarn lint` and `yarn build` pass with no errors
- `yarn dev` shows only "Panda Metrics" at `http://localhost:3000`, in light mode, regardless of the system theme
- No `app/` folder at the root and no `tailwind.config.*` file

## Repository

1. Load the SSH key into the agent (`ssh-add ~/.ssh/id_ed25519`). Right now the agent has no identities and `ssh -T git@github.com` returns `Permission denied (publickey)`
2. Confirm access with `ssh -T git@github.com` and confirm the key is added to the GitHub account with access to the Ellyonsoft organization
3. `git remote add origin git@github.com:Ellyonsoft/panda-metrics.git`
4. `git ls-remote origin` to check whether the remote is empty. If it already has commits (README, license), run `git pull --rebase origin main` before pushing. Never force-push
5. Commit the cleanup together with `context/` and `.claude/`. Keep `.next/`, `node_modules/`, `.env*` and `next-env.d.ts` ignored. Add `.claude/settings.local.json` to `.gitignore`
6. Commit message: `chore: clean boilerplate and set up Panda Metrics base`
7. `git push -u origin main` and confirm the default branch on GitHub is `main`
