# Panda Metrics

Panda Metrics collects feedback through a public kiosk, a shared link or a QR code, lets teams manage Satisfaction, Rating and Poll surveys, and turns the responses into reliable metrics.

See [context/project-overview.md](context/project-overview.md) for the product and technical overview.

## Getting started

Requirements: Node.js 20+ and Yarn 1.

```bash
yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command      | Description                  |
| ------------ | ---------------------------- |
| `yarn dev`   | Start the development server |
| `yarn build` | Build for production         |
| `yarn start` | Run the production build     |
| `yarn lint`  | Run ESLint                   |
