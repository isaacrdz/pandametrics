## 2. Next.js 16 notes (from `node_modules/next/dist/docs/`)

- **`LayoutProps` / `PageProps`** are global type helpers; no import is needed (`01-getting-started/03-layouts-and-pages.md`). The current `RootLayout({ children }: LayoutProps<"/">)` stays valid.
- **Metadata**: the `metadata` export only works in Server Components (`01-getting-started/14-metadata-and-og-images.md`). `layout.tsx` is a Server Component, so it stays there.
- **`src` folder** (`03-api-reference/03-file-conventions/src-folder.md`):
  - Move `app` to `src/app`. `src/app` is **ignored** if `app/` still exists at the root.
  - `public/`, `package.json`, `next.config.*`, `tsconfig.json` and `.env*` stay at the root.
  - Update the `@/*` path in `tsconfig.json` to include `src/`.
  - Proxy (`proxy.ts`, formerly middleware) must go inside `src/` when added.
  - The Tailwind note about `content` paths only applies to v3 `tailwind.config.js`. Tailwind v4 detects sources automatically, so no config file is needed.
- **Cache Components** (`cacheComponents: true`): a page with only static markup is prerendered with no extra work. Nothing in this feature needs `"use cache"` or `Suspense`.

### `src/app/layout.tsx`

```tsx
import type { Metadata } from "next";
import { Geist, Geist_Mono } from "next/font/google";
import "./globals.css";

const geistSans = Geist({
  variable: "--font-geist-sans",
  subsets: ["latin"],
});

const geistMono = Geist_Mono({
  variable: "--font-geist-mono",
  subsets: ["latin"],
});

export const metadata: Metadata = {
  title: "Panda Metrics",
  description:
    "Collect feedback by kiosk, link or QR, manage surveys and analyze their metrics.",
};

export default function RootLayout({ children }: LayoutProps<"/">) {
  return (
    <html
      lang="en"
      className={`${geistSans.variable} ${geistMono.variable} h-full antialiased`}
    >
      <body className="min-h-full flex flex-col">{children}</body>
    </html>
  );
}
```

- Keep `lang="en"` until next-intl is added; it will then come from the locale.
- Keep Geist: shadcn/ui's default setup uses the same `--font-sans` / `--font-mono` variables.

### `src/app/globals.css`

```css
@import "tailwindcss";

:root {
  --background: #ffffff;
  --foreground: #171717;
}

.dark {
  --background: #0a0a0a;
  --foreground: #ededed;
}

@theme inline {
  --color-background: var(--background);
  --color-foreground: var(--foreground);
  --font-sans: var(--font-geist-sans);
  --font-mono: var(--font-geist-mono);
}

body {
  background: var(--background);
  color: var(--foreground);
}
```

- Light is the default; the `prefers-color-scheme` media query is replaced by a `.dark` class, which is what `next-themes` and shadcn/ui toggle later.
- The `Arial` override is removed, so `font-sans` (Geist) applies. Because `@theme inline` sets `--font-sans`, Tailwind's preflight uses it on `html`.
- `shadcn@latest init` will later rewrite this file with its own tokens; keeping it minimal now avoids conflicts.

## 5. Repository

1. **SSH key**: load it into the agent (macOS keychain).

   ```bash
   ssh-add --apple-use-keychain ~/.ssh/id_ed25519
   ssh -T git@github.com
   # Hi <user>! You've successfully authenticated...
   ```

   If it still fails, add `~/.ssh/id_ed25519.pub` to the GitHub account and check that the account has write access to the Ellyonsoft organization (and SSO authorization if the org requires it).

2. **Remote**:

   ```bash
   git remote add origin git@github.com:Ellyonsoft/panda-metrics.git
   git ls-remote origin
   ```

   - No output: the repository is empty, go to step 3.
   - It lists `refs/heads/main`: the repository already has commits (README, license, `.gitignore`). Integrate them before pushing, never force-push:

     ```bash
     git fetch origin
     git pull --rebase origin main
     # if Git refuses because histories are unrelated:
     git pull origin main --allow-unrelated-histories
     ```

     Resolve conflicts (most likely `README.md` and `.gitignore`) keeping the local version plus anything the remote adds.

3. **Commit**:

   ```bash
   git add -A
   git status   # check: no .next/, node_modules/, .env*, .claude/settings.local.json
   git commit -m "chore: clean boilerplate and set up Panda Metrics base"
   ```

   Committed: the cleanup, `src/app/`, `tsconfig.json`, `.gitignore`, `README.md`, `context/`, `.claude/settings.json` and `.claude/skills/`.

4. **Push**:

   ```bash
   git push -u origin main
   ```

   On GitHub, check under Settings → General that the default branch is `main`.
